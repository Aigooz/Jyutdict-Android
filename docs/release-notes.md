## 稳定与易用性

- 修复地方资料在语法标记不足、`^` 空前缀等情况下的闪退；夜间模式下释义改用可读配色，不再接近背景色。
- 网络响应加入体积上限，异常大包不再耗尽内存；宽字表结果在转屏时改写入磁盘缓存，避开系统事务上限。
- 磁盘缓存按 30 天与 32MB 上限回收，查询记录读取走内存快照，评论区计数改为分批请求，部分失败不再整屏显示 0。
- 播放状态只刷新当前词条行，联网列表不再整表重建；检查结果配色与收藏来源文案随主题与语言显示。
- 检查更新遇 GitHub 限流会说明原因；缺少“安装未知应用”权限时先引导到系统设置，通知点击同样直达该页，不再下载完却装不上。
- 在其他应用选中文本可直接调用查词（取前 40 字），收藏词条长按可分享释义与来源。
- 主要按钮与图标触摸目标统一到 48dp；新增 Pull Request 检查工作流，沿用与发布相同的测试、lint 与打包步骤。

## 台山话中文释义

- 网站词典默认展示来源提供的普通话中文释义，粤语对应词和录音候选也优先中文显示。
- 英文释义及补充说明收进“英文原文”，不再直接铺满词条。
- 支持按需“翻译补充说明”，首次使用前说明 MyMemory 服务及数据发送范围；结果标明“中文机译”，不替换原词典数据。
- 翻译结果缓存 30 天，翻译失败可重试，不影响查词和联网发音；本机词库和音标保持原样。

## 地区排序修复

- 通用字表结果、地区筛选和发音筛选统一按行政归属排列，不再按地区名称或接口返回顺序交错显示。
- 江门、蓬江、江海、台山、新会、鹤山、开平、恩平集中连续显示；同一区县的采音点相邻排列。
- 化州、高州归入茂名，封川、开建归入肇庆，北流、容县、陆川、博白归入玉林，廉州归入北海。
- 兼容繁简地名和市、区、县后缀，保留各采音点、方言分片、原始读音和来源；历史音仍单独排在前面。
