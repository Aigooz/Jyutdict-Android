## 台山话中文释义

- 网站词典默认展示来源提供的普通话中文释义，粤语对应词和录音候选也优先中文显示。
- 英文释义及补充说明收进“英文原文”，不再直接铺满词条。
- 支持按需“翻译补充说明”，首次使用前说明 MyMemory 服务及数据发送范围；结果标明“中文机译”，不替换原词典数据。
- 翻译结果缓存 30 天，翻译失败可重试，不影响查词和联网发音；本机词库和音标保持原样。

## 地区排序修复

- 通用字表结果、地区筛选和发音筛选统一按行政归属排列，不再按地区名称或接口返回顺序交错显示。
- 江门、蓬江、江海、台山、新会、鹤山、开平、恩平集中连续显示；同一区县的采音点相邻排列。
- 化州、高州归入茂名，封川、开建归入肇庆，北流、容县、陆川、博白归入玉林，廉州归入北海。
- 兼容繁简地名和市、区、县后缀，保留各采音点、方言分片、原始读音和来源；历史音仍单独排在前面。
