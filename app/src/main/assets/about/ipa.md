# IPA 例字速查

这里用常见字做锚点，帮你更快看懂陌生音标。例子以标准广州音为主，地方音可能略有偏差。遇到不熟悉的记音，先把它拆成「声母 + 韵腹/韵尾 + 声调」来看。

## 声母

| IPA | 例字 | 提示 |
| --- | --- | --- |
| [p] | 巴、板 | 不送气，接近普通话 b 的口型 |
| [pʰ] | 爬、破 | 送气，接近普通话 p |
| [t] | 打、多 | 不送气 |
| [tʰ] | 他、天 | 送气 |
| [k] | 家、高 | 不送气 |
| [kʰ] | 卡、开 | 送气 |
| [kʷ] | 瓜、广 | 圆唇的 k |
| [kʷʰ] | 夸、亏 | 圆唇且送气 |
| [ts] | 渣、章 | 不送气塞擦音 |
| [tsʰ] | 茶、车 | 送气塞擦音 |
| [s] | 沙、山 | 摩擦音 |
| [f] | 花、风 | 唇齿摩擦音 |
| [m] | 妈、门 | 鼻音 |
| [n] | 拿、男 | 鼻音 |
| [ŋ] | 牙、我 | 鼻音，通常写作 ng |
| [l] | 拉、蓝 | 边音 |
| [h] | 虾、好 | 送气摩擦音 |
| [j] | 也、叶 | 硬腭近音，常写作 j |
| [w] | 华、王 | 圆唇近音，常写作 w |

## 元音与韵腹

| IPA | 例字 | 提示 |
| --- | --- | --- |
| [aː] | 家、妈 | 长而张口大的 a |
| [ɐ] | 心、根 | 较短、位置偏中的 a |
| [iː] | 衣、医 | 高前元音，长 |
| [ɪ] | 英、行 | 较短且略松的 i |
| [e] | 基、悲 | 常出现在 [ei] 类韵母中 |
| [ɛː] | 蛇、写 | 半开元音 |
| [œː] | 靴 | 圆唇前元音 |
| [yː] | 鱼 | 圆唇高前元音 |
| [ɵ] | 春、信 | 较短、圆唇偏央 |
| [ɔː] | 我、多 | 后元音，略低 |
| [o] | 高、好 | 常出现在 [ou] 类韵母中 |
| [uː] | 夫、湖 | 高后元音，长 |
| [ʊ] | 足、谷 | 较短、偏松的 u |

常见组合：[ai] 太，[ɐi] 西，[au] 貓，[ɐu] 九，[ei] 基，[ou] 高，[ɔi] 开，[ui] 回。

## 韵尾

| IPA | 例字 | 提示 |
| --- | --- | --- |
| [m] | 心、南 | 收音时双唇闭住 |
| [n] | 山、男 | 舌尖抵上齿龈 |
| [ŋ] | 生、红 | 舌根靠软腭 |
| [p] | 十、急 | 入声，不爆破 |
| [t] | 七、竹 | 入声，不爆破 |
| [k] | 石、六 | 入声，不爆破 |

如果看到 [p̚]、[t̚]、[k̚]，意思和 [p]、[t]、[k] 一样，只是强调“没有释放”，不是另一个音。

## 声调

| 调号 | 调值 | 例字 | 听感 |
| --- | --- | --- | --- |
| 1 | 55 / [˥˥] | 家、心 | 高平 |
| 2 | 35 / [˧˥] | 好、口 | 上扬 |
| 3 | 33 / [˧˧] | 世、菜 | 中平 |
| 4 | 21 / [˨˩] | 前、田 | 低降 |
| 5 | 13 / [˩˧] | 女、老 | 低升 |
| 6 | 22 / [˨˨] | 事、慢 | 低平 |

[˥]、[˧]、[˨]、[˩] 这些小符号不是元音，而是声调记号：越往上越高，越往下越低。入声一般用 [-p]、[-t]、[-k] 韵尾配合 1/3/6 的调值，如八、百、六。

## 少见符号

| IPA | 常见理解 | 例字 |
| --- | --- | --- |
| [ə] | 央元音，类似轻声呃 | 视方言而定 |
| [æ] | 前低元音，介于 a 和 e 之间 | 视方言而定 |
| [ɕ] | 齿龈前腭音，略像普通话 x | 视方言而定 |
| [ʃ] | 齦后音，略像普通话 sh | 视方言而定 |
| [θ] | 齿间音，英语 thin 的 th | 视方言而定 |
| [ɲ] | 鼻音略带腭化，接近 nj | 视方言而定 |

方言记音会按当地音系补充符号，所以不必硬套标准音。先找最像的一个例字，再结合上下文、地音表或点击发音确认。
